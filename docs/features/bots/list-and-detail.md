# Список ботов и страница бота

Страницы: `/bots` (компактные карточки и сводка), `/bots/:id` (всё, что фронт знает о боте).

## Данные

- Список: `GET /bots` один раз **без фильтров** + WebSocket `/ws/bots`. Фильтры «Все / Активные / Остановленные / Закрытые», «Избранные» и «Требуют внимания» работают на клиенте, поэтому сводка всегда считается по всем ботам.
- Отдельного `GET /bots/{id}` нет: `/bots/:id` берёт бота из того же списка. «Бота нет в списке» показывается только после загрузки списка, без мигания при SSR.
- События страницы: `GET /bots/history?bot_id=&limit=500` (максимум сервера: движок в ошибке пишет событие примерно раз в минуту, меньшая страница теряет начало цикла). По WebSocket они не приходят, поэтому страница перезапрашивает их (с задержкой 1,5 с), когда у бота меняется статус, состояние движка, версия настроек, размер позиции, средний вход или `updated_at`. Исполнение доливки меняет только позицию, поэтому размер и вход тоже в списке.
- Свечи: `recent_candles`, только у anti-martingale. Если тик пришёл без свечей (`null`), график остаётся прежним. Свечи с пустой или нечисловой ценой отбрасываются.

## `/bots`

### Сводка

| Плитка | Как считается |
|--------|---------------|
| Общий PnL, USDT | сумма `unrealized_pnl` активных ботов в позиции; «—», если таких нет |
| Работают X из N | `lifecycle_status = ACTIVE` и `engine_state ≠ ERROR` |
| В позиции | активные боты с `position_size ≠ 0` (сервер отдаёт 0, когда позиции нет) |
| Требуют внимания | `engine_state = ERROR`; плитка — кнопка-фильтр, при 0 неактивна. Включение сбрасывает вкладку и «Избранные», выбор вкладки или «Избранных» выключает её |

### Карточка

Звезда (избранное), символ (ссылка на `/bots/:id`, кликабельна вся карточка), логотип биржи на белой плашке, направление, меню «⋯». Строки: тип, статус, PnL в USDT («—» без позиции).

- Направление: anti-martingale всегда LONG; сетка — `config.direction`, иначе `position_side`. Сам `position_side` не используется: сервер хранит последнюю сторону и при пустой позиции.
- Отрицательный PnL белый, как на макете. Красный — заменить цвет в `.bot-tile__pnl--down` на `var(--color-down)`.
- Ошибка движка: красная рамка, статус «Ошибка» и две строки `engine_error` прямо в карточке (подсказки на телефоне не открываются), полный текст на странице бота.
- Позиции остановленных ботов сервер больше не обновляет, а у закрытых не очищает. Закрытый бот считается без позиции, PnL остановленного показан приглушённо и в сводку не входит.

Статус, по приоритету:

| Условие | Подпись |
|---------|---------|
| `engine_state = ERROR` | Ошибка |
| `CLOSED` / `STOPPED` | Закрыт / Остановлен |
| `INIT` | Запускается |
| `RESTARTING` | Перезапуск |
| движок `STOPPED` | Движок остановлен |
| anti-martingale без позиции | Ждёт пробоя |
| иначе | Работает |

Меню «⋯»: Открыть, История; для сетки — «Ордера сетки» (смешанная сетка), Take-profit и Stop-loss с текущими значениями; Остановить, Перевыставить сетку, Закрыть; Убрать. Пункты те же, что на странице бота, логика общая (`useBotActions`).

## `/bots/:id`

| Блок | Что показывает |
|------|----------------|
| Шапка | символ, биржа, направление, статус, тип, id, дата создания; кнопки действий с текущими TP / SL |
| Позиция | PnL USDT, PnL % (ROE на маржу, `pnl_percent`), размер, цена входа, текущая цена, цена от входа %, стоимость позиции, цель take-profit сетки «≈» |
| Anti-martingale | график, уровень пробоя, расстояние до пробоя, тренд EMA, число циклов, текущий цикл с лесенкой доливок, таблица циклов |
| Цикл смешанной сетки | депозит, номинал, цена привязки, ордера цикла с отметкой «Исполнен», завершённые циклы с PnL, комиссиями и funding |
| События | последние события бота по 15, ссылка «Вся история» |
| Настройки | все поля `config` в виде, как в истории создания |
| О боте | id, тип, биржа, API-ключ, статусы, версия настроек, даты |

Размер позиции: OKX отдаёт контракты («контр.»), Binance — монеты. Стоимость позиции считается только для монет.

Цель take-profit сетки: `вход × (1 ± N/100)` для процента, `вход ± N / размер` для суммы в USDT. Пока идёт цикл смешанной сетки, берётся замороженный конфиг цикла (`cycle_state.cycle.config`): сохранённые настройки действуют со следующего цикла.

Остановка и закрытие снимают все ордера бота, а цикл смешанной сетки при этом не закрывается. Поэтому у неактивного бота нет цели take-profit, trailing stop и ожидающих доливок, ордера цикла не считаются выставленными, а блок называется «Последний цикл сетки». «Депозит следующего цикла» показывается только между циклами и выбирается по правилу движка: накопленный депозит, если поле депозита не меняли.

### Anti-martingale

Расчёты повторяют `app/strategies/anti_martingale.py` бэкенда:

- уровень пробоя — максимум `high` свечей окна (`breakout_lookback_hours × 4` свечей 15m);
- вход, когда свеча закрылась выше уровня и EMA быстрая > EMA медленная (EMA с SMA-стартом);
- цикл начинается с `cycle_started` (движок поднимает `config_version`), запущено циклов = `config_version − 1`;
- доливка: триггер = первый вход × (1 + триггер %/100), сумма = баланс на старте цикла × размер %/100;
- trailing stop ≈ максимум с входа × (1 − trailing %/100).

Что помечено «≈» и почему:

- первый вход: движок отмечает рыночный вход исполненным сразу и событие `order_filled` для `o0` почти никогда не пишет. Цена берётся из позиции, пока доливок не было, иначе из доливки (`цена доливки / (1 + триггер %)`), иначе открытие свечи начала цикла;
- доливки и выход: в `avg_price` и `exit_price` движок пишет цену триггера, а не исполнения;
- максимум с входа: только свечи за последние 1500 минут, как у движка (он читает до 1500 минутных свечей), плюс текущая цена;
- EMA: на странице только окно пробоя, а движок берёт историю длиннее, поэтому у самого пересечения тренд может отличаться.

У остановленного бота с позицией доливки показаны «Снят», trailing stop не считается, сверху предупреждение, что позицию ничто не защищает.

График: наведение, касание или стрелки на клавиатуре показывают OHLC свечи, изменение, размах и значения EMA. Линии: уровень пробоя (пока нет цикла), средний вход, ожидающие доливки, ≈ trailing stop. Метки: вход, доливки, выход. Далёкие уровни растягивают шкалу, только пока свечи занимают не меньше 45 % высоты; остальные показаны меткой ▲ / ▼ у края шкалы без линии.

## Чего нет без бэкенда

- цена ликвидации открытой позиции;
- реальные цены trailing stop и доливок с биржи;
- реализованный PnL по циклам anti-martingale (в таблице только изменение цены выход / вход);
- объём и другие таймфреймы свечей;
- `GET /bots/{id}`;
- на OKX запрос свечей ограничен 300, а окно 99 ч — 396 свечей;
- плечо anti-martingale в настройках есть, но движок его не применяет;
- после первого закрытого цикла anti-martingale движок не входит снова: `_ensure_anti_martingale_entry` видит ордер `o0` текущей версии и выходит, а версия растёт только при входе. Страница при этом пишет «Ждёт пробоя».
